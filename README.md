# Task 1: Shopify Store Audit & UX Review
Audited Store: Outfitters Pakistan (outfitters.com.pk)
Focus: Mobile Conversion Rate Optimization (CRO) & Friction Points

## 1. Homepage Audit (Screenshot 1)
- Bottleneck: Large full-screen hero image (FW collection banner) without a direct, clear Call-to-Action (CTA) button like "Shop Men" or "Shop New Arrivals" directly on top of the banner.
- Impact: Increases bounce rate because users have to scroll or rely on faint navigation links to start shopping.
- Solution: Add high-contrast sticky CTA buttons ("Shop Men" / "Shop Women") directly over the hero image and optimize the banner format to WebP under 150 KB for faster mobile rendering.

## 2. Product Page Audit (Screenshot 2)
- Bottleneck 1 - Missing Instant Buy Option: The page only shows "ADD TO CART" without an instant "Buy Now / Cash on Delivery" 1-click checkout button.
- Bottleneck 2 - Floating Widget Obstruction: A floating notification/chat bell widget in the bottom right corner partially covers product details and adds UI clutter.
- Bottleneck 3 - Hidden Trust Badges: Return policies, delivery timelines (e.g., 2–4 days), and exchange terms are not visible near the Add to Cart button, creating doubt for first-time buyers.
- Solution: 
  1. Add a direct "Buy with Cash on Delivery" button.
  2. Relocate or minimize the floating bell icon.
  3. Place 3 visual trust icons right below the purchase button: "Free 7-Day Exchange", "Cash on Delivery", and "Fast Nationwide Shipping".
